# 敦煌星图 · Dunhuang Sky

以唐代敦煌星图（大英图书馆藏 Or.8210/S.3326）为主题的沉浸式交互网站。

- **掌灯观星**：光标化作一盏灯，照见夜空下的纸本星图
- **十二次长卷**：滚动时星图自右向左展开，从玄枵到星纪
- **斗转星移**：拖动年份，观察岁差带来的北极星更替
- **三家星**：按石氏、甘氏、巫咸筛选星点

单文件静态页面，无需构建。直接打开 `index.html`，或在仓库 Settings → Pages 中启用 GitHub Pages。

星位取自 J2000 星表；二十八宿、北斗、紫微诸星按实测位置绘出，其余细小星点为示意分布。
