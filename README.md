# 敦煌星图 · Dunhuang Sky

以唐代敦煌星图为主题的沉浸式交互网站。这卷星图出自敦煌莫高窟藏经洞，绘于唐初，是世界现存最古老、星数最多的全天星图之一，完整记录了中国古代的三家星官体系。

- **掌灯观星**：灯光所及，夜空化作千年写本，星官以朱、墨、黄三色逐笔画出
- **十二次长卷**：滚动时星图自右向左展开，从玄枵到星纪
- **斗转星移**：拖动年份，观察岁差带来的北极星更替
- **三家星**：按石氏、甘氏、巫咸筛选星点

单文件静态页面，无需构建，直接打开 `index.html` 即可。

星位取自 J2000 星表；二十八宿、北斗、紫微诸星按实测位置绘出，其余细小星点为示意分布。
